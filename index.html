Ansvarsfriskrivning: Detta är en teknisk analysmotor, inte finansiell rådgivning. Signalerna genereras automatiskt av regler i webbläsaren och kan vara fel. Marknadsdata kan vara fördröjd. Handla aldrig enbart på detta — riskera bara kapital du har råd att förlora.

Inställningar

Marknadsdata hämtas från Yahoo Finance chart-API. Webbläsare blockerar det direkt (CORS), därför krävs oftast en proxy. Om allt fallerar visas simulerad data med varning. Kör du sidan via npm start fylls fältet automatiskt med den lokala proxyn http://localhost:8080/proxy?url=, som hämtar från din egen uppkoppling — den fungerar när de publika proxyerna strular.
Lämna tomt för att bara köra Yahoo. Ifylld används realtidsstaplarna från dina TradingView-alerts, med Yahoo som historik så att EMA och ATR blir uppvärmda. Kör du sidan via npm start ligger en lokal kopia av workern på http://localhost:8080/feed. Inställningarna sparas i webbläsaren.
Alla mål klipps till detta spann — day trades bara.
